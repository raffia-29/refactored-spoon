# Simple Calculator

A lightweight calculator built with plain HTML, CSS, and JavaScript. No frameworks or dependencies are required.

## Run it

Open `index.html` in any modern web browser.

## Features

- Addition, subtraction, multiplication, and division
- Clear and delete controls
- Decimal number support
- Keyboard support: press **Enter** or **=** to calculate, and **Escape** to clear
- Responsive layout

## Project files

- `index.html` — calculator markup, styles, and functionality
